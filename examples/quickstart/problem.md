# 绿色生产计划优化

某工厂生产 A、B、C 三类产品。每件产品需要不同的装配工时、检测工时、原材料和碳排放额度，并产生不同利润。请建立数学模型，确定三类产品的生产数量，使总利润最大。

## 任务

1. 建立整数规划模型。
2. 求出最优生产计划和最大利润。
3. 分析各资源约束的使用情况。
4. 输出结果表，并至少生成一张可视化图表。

## 约束

- 三类产品产量均为非负整数。
- 资源消耗不能超过附件数据中的总容量。
- 每类产品产量不能超过附件数据中的需求上限。

## 输出要求

- `writer_prompt.md`：交接模型假设、变量、目标函数、约束、结果证据和后续写作注意事项；不生成正式写作正文。
- `solution.py` 或 `solution.m`：可运行代码。
- `results/`：保存结果表和图表。
