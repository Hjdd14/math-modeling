# 模型裁决

五视角建模 Agent 均认为该题是小规模整数优化。动态专家建议保留枚举 oracle，最终选择整数枚举模型；贪心模型作为 baseline。

## 求解目标

- 确定 A、B 产品的整数产量。
- 最大化总利润。
- 给出 baseline 对比、oracle 验证和敏感性分析。

## 变量与目标函数

- `x_a`：A 产品产量，单位为件，要求为非负整数。
- `x_b`：B 产品产量，单位为件，要求为非负整数。
- 目标函数：最大化 `40*x_a + 55*x_b`。

## 约束条件

- 工时约束：`2*x_a + 3*x_b <= 120`。
- 材料约束：`3*x_a + 4*x_b <= 160`。
- 碳排约束：`x_a + 2*x_b <= 70`。
- 非负整数约束：`x_a, x_b` 为非负整数。

## 裁决理由

该题数据规模小，完整枚举能覆盖所有可行整数点，天然形成 oracle；贪心 baseline 用于解释完整模型的增益，资源残差、利润扰动和多种子稳定性用于支撑结果可复现。
