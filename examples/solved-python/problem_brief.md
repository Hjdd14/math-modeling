# 题目简报

## 1. 题目原文

某工厂生产 A、B 两类产品。每件产品消耗工时、材料并产生利润与碳排。请在工时、材料和碳排上限内，确定整数生产数量，使总利润最大。

## 2. 求解目标

- 确定 A、B 产品的整数产量。
- 最大化总利润。
- 给出 baseline 对比、oracle 验证和敏感性分析。

## 3. 已知条件与参数

| 条件/参数 | 值 | 单位 | 备注 |
|-----------|----|------|------|
| A 产品利润 | 40 | 元/件 | 工时2、材料3、碳排1 |
| B 产品利润 | 55 | 元/件 | 工时3、材料4、碳排2 |
| 工时上限 | 120 | 小时 | 总量 |
| 材料上限 | 160 | kg | 总量 |
| 碳排上限 | 70 | kgCO2 | 总量 |

## 4. 约束条件

- 工时约束：2*x_a + 3*x_b <= 120。
- 材料约束：3*x_a + 4*x_b <= 160。
- 碳排约束：x_a + 2*x_b <= 70。
- 非负整数约束：x_a, x_b 为非负整数。

## 5. 附件数据

`data.csv` 包含产品、利润、工时、材料和碳排字段。

## 6. 输出要求

- 最优生产方案。
- baseline 对比。
- 资源利用率图。
- 约束残差、oracle 验证和敏感性分析。
