# 奖项级方法谱系 Playbook

本文件用于 Phase 1 的题库检索 Agent、动态专家 Agent 和创新筛选 Agent。它沉淀国赛展示、COMAP previous contests 和国内公开竞赛入口中的题型、方法、验证方式和图表证据启发，不复制优秀论文正文，不把案例当作可照搬模板。

## 来源范围

- 国赛展示入口：2012-2025 全国大学生数学建模竞赛优秀论文展示入口，来源为中国大学生在线。
- COMAP previous contests：2018-2026 MCM/ICM previous contests、results、instructions 和 FAQ。
- 国内权威专项竞赛：研究生数学建模、统计建模、MathorCup、电工数学建模、深圳杯。
- 国内训练竞赛：APMCM、五一、认证杯、华中杯、中青杯、华数杯、数维杯。
- 来源总索引见 `references/competition_sources.json`；方法卡只引用可核验入口。

官方入口：

- 中国大学生在线数学建模展示入口：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml
- COMAP previous contests：https://www.contest.comap.com/undergraduate/contests/mcm/previous-contests.php
- COMAP instructions：https://www.contest.comap.com/undergraduate/contests/mcm/instructions.php

## 使用规则

1. 题库检索 Agent 只抽象候选方法、验证方式和图表证据，不复制作品正文。
2. 相似题型只提供启发，不替代 `problem_brief.md` 的题意审计。
3. 创新点进入 `innovation_register.json` 前，必须能被 baseline、消融、敏感性分析或 oracle 支撑。
4. 若方法依赖外部资料或软件库，必须在 `compliance_record.json` 和 `reproducibility_manifest.json` 中记录。
5. 每张方法卡都必须可追溯到 `competition_sources.json` 中的来源比赛。

## 方法卡片

### 优化调度

图网络路径、资源分配、排产、选址和容量约束类问题优先从本节抽象变量、约束和验证方式。

#### 方法卡 OPT-01 线性规划基线
- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2024
- 题号：A/B 类资源分配题
- 适用条件：目标与主要约束可线性化，变量规模中等。
- 误用风险：忽略整数性、时间窗或单位换算会得到不可执行解。
- 推荐验证：小规模枚举 oracle、约束残差、baseline 不劣化。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 OPT-02 整数规划与启发式修复
- 来源比赛：MathorCup 数学应用挑战赛及大数据竞赛
- 年份：2023
- 题号：B 类排程题
- 适用条件：存在 0-1 选择、排班、装载或路径组合。
- 误用风险：只给启发式结果而无可行性证明，容易被复现评委质疑。
- 推荐验证：整数可行性检查、松弛下界、随机扰动稳定性。
- 来源链接：https://www.mathorcup.org/

#### 方法卡 OPT-03 多阶段调度
- 来源比赛：中国研究生数学建模竞赛 / 华为杯 NPMCM
- 年份：2022
- 题号：工业调度类题
- 适用条件：决策随时间滚动更新，前期结果影响后期容量。
- 误用风险：把多阶段问题压成单阶段会漏掉库存、延迟或切换成本。
- 推荐验证：滚动窗口回放、阶段可行性不变量、情景对比。
- 来源链接：https://cpipc.acge.org.cn/cw/hp/4

#### 方法卡 OPT-04 约束紧张度解释
- 来源比赛：深圳杯数学建模挑战赛
- 年份：2021
- 题号：工程约束决策题
- 适用条件：评委需要知道最优解受哪些资源或工程约束限制。
- 误用风险：只报告最优值，不解释约束瓶颈和可执行余量。
- 推荐验证：影子价格或边际收益、资源利用率图、敏感性条形图。
- 来源链接：https://www.m2ct.org/

### 预测统计

#### 方法卡 STA-01 朴素预测 baseline
- 来源比赛：全国大学生统计建模大赛
- 年份：2024
- 题号：社会经济预测题
- 适用条件：存在时间序列、分组指标或外推需求。
- 误用风险：直接上复杂模型而缺少 naive baseline，无法证明增益。
- 推荐验证：滚动预测、MAE/RMSE/MAPE、残差诊断。
- 来源链接：http://tjjmds.ai-learning.net/

#### 方法卡 STA-02 分层回归
- 来源比赛：COMAP MCM/ICM
- 年份：2021
- 题号：开放预测类题
- 适用条件：样本来自不同地区、群体或层级，参数可能异质。
- 误用风险：把所有样本混合建模会掩盖群体差异。
- 推荐验证：分层 holdout、参数稳定性、置信区间。
- 来源链接：https://www.contest.comap.com/undergraduate/contests/mcm/previous-contests.php

#### 方法卡 STA-03 异常值影响审计
- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2020
- 题号：数据分析类题
- 适用条件：附件数据有缺失、跳点、极端值或口径变化。
- 误用风险：删除异常值但不说明依据，会被视为人为筛选结果。
- 推荐验证：保留/剔除双版本、鲁棒统计量、异常点标注图。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 STA-04 预测区间表达
- 来源比赛：APMCM 亚太地区大学生数学建模竞赛中文赛项
- 年份：2022
- 题号：趋势预测题
- 适用条件：评审关注不确定性而不是单点预测。
- 误用风险：把预测均值当成确定结论，忽略置信或预测区间。
- 推荐验证：bootstrap 区间、覆盖率回测、区间宽度解释。
- 来源链接：https://www.apmcm.org/

### 图网络路径

图网络路径问题包括最短路、连通性、最小费用流、车辆路径、补给约束和传播网络。

#### 方法卡 NET-01 小图 oracle
- 来源比赛：COMAP MCM/ICM
- 年份：2019
- 题号：网络传播或路径题
- 适用条件：主问题图规模较大，但可构造小规模子图。
- 误用风险：只在大图上跑算法，无法证明路径逻辑正确。
- 推荐验证：手算小图 oracle、连通性不变量、路径成本复算。
- 来源链接：https://www.contest.comap.com/undergraduate/contests/mcm/previous-contests.php

#### 方法卡 NET-02 最小费用流
- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2022
- 题号：运输与分配题
- 适用条件：供需平衡、容量限制和单位运输成本明确。
- 误用风险：把费用和距离混用，或忽略供需不平衡的虚拟节点。
- 推荐验证：流量守恒、容量残差、网络图与表格双证据。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 NET-03 时空网络
- 来源比赛：MathorCup 数学应用挑战赛及大数据竞赛
- 年份：2021
- 题号：出行或物流数据题
- 适用条件：边权随时间变化，节点状态存在时段差异。
- 误用风险：静态图会漏掉拥堵、等待和服务时间窗口。
- 推荐验证：分时段回放、禁行边测试、时间窗违反率。
- 来源链接：https://www.mathorcup.org/

#### 方法卡 NET-04 网络鲁棒性
- 来源比赛：深圳杯数学建模挑战赛
- 年份：2023
- 题号：城市或工程网络题
- 适用条件：需要评估节点失效、边中断或应急替代路径。
- 误用风险：只给正常情景最优路径，无法解释风险韧性。
- 推荐验证：节点删除实验、连通分量变化、最差情景损失。
- 来源链接：https://www.m2ct.org/

### 随机仿真

#### 方法卡 SIM-01 多随机种子仿真
- 来源比赛：COMAP MCM/ICM
- 年份：2020
- 题号：随机策略评估题
- 适用条件：模型含随机到达、随机扰动或策略模拟。
- 误用风险：单次仿真结果可能只是随机波动。
- 推荐验证：固定种子、多种子稳定性、均值和标准差报告。
- 来源链接：https://www.contest.comap.com/undergraduate/contests/mcm/previous-contests.php

#### 方法卡 SIM-02 排队系统近似
- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2019
- 题号：服务系统类题
- 适用条件：到达、服务和等待时间是主要矛盾。
- 误用风险：不检验稳态条件会得到无意义等待时间。
- 推荐验证：Little 定律、极端负载测试、仿真收敛曲线。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 SIM-03 情景树
- 来源比赛：中国研究生数学建模竞赛 / 华为杯 NPMCM
- 年份：2020
- 题号：风险决策题
- 适用条件：不确定性可离散为若干高/中/低情景。
- 误用风险：情景概率拍脑袋且不做权重敏感性。
- 推荐验证：情景概率扰动、minimax regret、代表情景解释。
- 来源链接：https://cpipc.acge.org.cn/cw/hp/4

#### 方法卡 SIM-04 方差缩减
- 来源比赛：APMCM 亚太地区大学生数学建模竞赛中文赛项
- 年份：2023
- 题号：蒙特卡洛估计题
- 适用条件：仿真成本较高，普通抽样方差过大。
- 误用风险：方差缩减后没有说明估计无偏性或可比性。
- 推荐验证：普通抽样对照、置信区间宽度、重复实验。
- 来源链接：https://www.apmcm.org/

### 物理机理

#### 方法卡 PHY-01 量纲分析
- 来源比赛：深圳杯数学建模挑战赛
- 年份：2020
- 题号：工程物理题
- 适用条件：变量单位复杂，参数来自不同量纲来源。
- 误用风险：公式形式正确但单位不一致，数值结论失真。
- 推荐验证：symbol_table.json、单位换算表、极端量纲检查。
- 来源链接：https://www.m2ct.org/

#### 方法卡 PHY-02 守恒约束
- 来源比赛：中国电机工程学会杯全国大学生电工数学建模竞赛
- 年份：2022
- 题号：能量或电路约束题
- 适用条件：存在质量、能量、电荷或流量守恒。
- 误用风险：只拟合数据不守恒，外推时产生物理不可能结果。
- 推荐验证：守恒残差、节点平衡、边界条件审计。
- 来源链接：https://shumo.neepu.edu.cn/

#### 方法卡 PHY-03 微分方程离散化
- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2018
- 题号：动态过程题
- 适用条件：状态随时间连续变化，需数值求解。
- 误用风险：步长过大导致数值不稳定，边界条件含糊。
- 推荐验证：步长收敛、已知特例、稳定性区域检查。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 PHY-04 机理校准
- 来源比赛：中国研究生数学建模竞赛 / 华为杯 NPMCM
- 年份：2024
- 题号：工业参数辨识题
- 适用条件：物理结构明确但关键参数需由数据估计。
- 误用风险：过拟合参数，缺少可解释范围或独立验证。
- 推荐验证：参数置信区间、留出工况、残差物理解释。
- 来源链接：https://cpipc.acge.org.cn/cw/hp/4

### 电力电工

#### 方法卡 ELE-01 负荷预测加调度

- 年份：2024
- 题号：A 类负荷题
- 适用条件：负荷预测结果直接进入后续调度或容量规划。
- 误用风险：预测误差未传递到调度，会夸大方案稳定性。
- 推荐验证：滚动预测、备用容量敏感性、峰谷误差分析。

#### 方法卡 ELE-02 潮流近似

- 年份：2023
- 题号：输电网络题
- 适用条件：题目给出节点、线路、电压或功率约束。
- 误用风险：把一般网络流当成电力潮流，忽略物理约束。
- 推荐验证：节点功率平衡、电压/容量约束、已知工况回放。

- 适用条件：附件包含电流、电压、转速、磁场或温升数据。
- 误用风险：纯黑箱拟合无法解释控制参数和物理边界。
- 推荐验证：参数范围检查、工况外推、单位一致性。
- 来源链接：https://shumo.neepu.edu.cn/

#### 方法卡 ELE-04 新能源并网情景

- 年份：2020
- 题号：新能源调度题
- 适用条件：风光出力、储能、负荷和电价同时影响决策。

### 统计调查

#### 方法卡 SUR-01 抽样设计
- 来源比赛：全国大学生统计建模大赛
- 年份：2023
- 题号：问卷调查题
- 适用条件：题目要求从样本推断总体或比较群体差异。
- 误用风险：样本偏差和非响应偏差未处理，结论代表性不足。

- 来源比赛：全国大学生统计建模大赛

- 题号：社会经济评价题
- 适用条件：多个观测指标共同描述发展水平或风险等级。
- 误用风险：指标重复计权，或者方向正负没有统一。
- 推荐验证：相关性筛选、权重敏感性、一致性检查。
- 来源链接：http://tjjmds.ai-learning.net/

#### 方法卡 SUR-03 实证回归与稳健性
- 来源比赛：全国大学生统计建模大赛

- 题号：影响因素分析题
- 适用条件：需要解释变量对结果变量的影响方向和强度。
- 误用风险：把相关当因果，遗漏混杂变量。
- 推荐验证：替代变量、分组回归、稳健标准误。
- 来源链接：http://tjjmds.ai-learning.net/

#### 方法卡 SUR-04 问卷质量控制
- 来源比赛：认证杯数学中国数学建模国际赛 / 数学中国网络挑战赛

- 适用条件：数据来自问卷、打分或人工填报。
- 误用风险：无效问卷、直线作答和极短作答时长未剔除。
- 推荐验证：一致性检验、异常作答标记、剔除前后对比。
- 来源链接：http://mcm.tzmcm.cn/index.html

### 多目标鲁棒

#### 方法卡 ROB-01 Pareto 前沿
- 来源比赛：COMAP MCM/ICM
- 年份：2022
- 题号：开放政策权衡题
- 适用条件：至少两个目标存在明显冲突，需要展示取舍。
- 误用风险：随意加权导致结论依赖主观权重。

- 来源比赛：高教社杯全国大学生数学建模竞赛 CUMCM
- 年份：2023
- 题号：多目标规划题
- 适用条件：一个目标作为主目标，其他目标可转化为阈值约束。
- 误用风险：阈值缺乏业务解释，导致不可执行或过松。
- 推荐验证：阈值敏感性、约束紧张度、代表解表。
- 来源链接：https://dxs.moe.gov.cn/zx/hd/sxjm/sxjmlw/qkt_sxjm_lw_lwzs.shtml

#### 方法卡 ROB-03 minimax regret
- 来源比赛：中国研究生数学建模竞赛 / 华为杯 NPMCM
- 年份：2021
- 题号：不确定决策题
- 适用条件：情景概率难以准确估计，但希望控制后悔值。

- 来源链接：https://cpipc.acge.org.cn/cw/hp/4

#### 方法卡 ROB-04 权重稳定性热力图
